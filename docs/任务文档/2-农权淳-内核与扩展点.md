**边界（判分重点）**：`src/kernel/` 与 `src/cli/` 属于内核，**不许出现任何具体插件名**（`box`、`stats`、`dir`）。六个内置插件由 `src/index.ts` 这个装配处 import 并 activate——装配处允许依赖具体插件，内核不允许。

## 5. 容易踩的坑

1. **`help` 的逐字节一致**是硬指标。`HELP_LINES` 里有大量手工对齐的空格，改成插件后如果重新格式化就会差几个空格，直接判失败。做法：把每行原文切到各插件的 `help` 字段里，不要重新排版。
2. **`SnapshotCommand` 的 try/catch 不能吞异常**：`restoreFrom` 之后必须原样 `throw`，否则 `CommandHistory.execute` 会把失败当成功、推入 undo 栈。
3. **`Repl.dispatch` 现在按名字特判 `init/read/help`**，改成 `requiresDocument` 后要确认 `undo/redo` 仍然要求有文档（它们不走 registry）。
4. **六图形迁移必须在 D4 前完成**（张杰负责），否则「禁插件仍能跑 Phase 1」这条你没法验证——D2 起每天和他对一次进度。
5. **`Document.add` 本身是原子的**（先 `collectIds` 查全树、后 `insertAt`），`box` 那边靠这个特性避免残骸，不要额外加锁或半途插入的写法。
6. **别在 `src/kernel/` 里写 `if (kind === 'box')`**。任何类型特判都要变成接口方法（比如 `canUngroup`），否则第 1 节判据直接不过。

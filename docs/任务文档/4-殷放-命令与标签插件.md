## 2. 任务

### 2.1 命令

| # | 任务 | 内容 | 完成标准 |
|---|---|---|---|
| C1 | `stats` | 从 `document.children` DFS；叶子（`!acceptsChildren()`）按 `kind` 计数，类型顺序 = 首次出现顺序；`g`/`box` 计入 containers，根 SVG 不计；`box` 内叶子照常计数；空文档 `(total 0, containers 0)` | 输出形如 `rect: 3  circle: 1  text: 2  (total 6, containers 2)`；执行后 undo 栈不变 |
| C2 | `stats` 的命令声明 | `kind = 'display'`、`requiresDocument = true`、自带 name/usage/help 文案 | 出现在 `help` 里；卸载后执行报 `error: unknown command: stats` |
| C3 | 目录访问接口 | `DirectoryLister.list(path): DirEntry[]`，`DirEntry = { name, kind: 'dir' \| 'file' \| 'other' }` | 命令逻辑不 import `node:fs`，只依赖这个接口 |
| C4 | Node 适配器 | `readdirSync(path, { withFileTypes: true })` → `DirEntry`；符号链接 `isSymbolicLink()` → 归 `file`，不跟随目标 | 真实临时目录测试通过 |
| C5 | `dir` 命令 | 0 参数；`[DIR]`/`[FILE]` + **两个空格** + 名字；目录在前、文件在后，各组按名字升序（用 `<` 码点比较，**不要用 `localeCompare`**，否则双装配可能不一致）；含隐藏项、不含 `.`/`..`；不递归 | 两次执行输出逐字节一致；顺序稳定 |
| C6 | `dir` 的空与错 | 空目录输出 `(empty directory)`；读失败输出 `error: cannot read directory: <path>`（路径用 `process.cwd()`），失败后仍可继续敲命令 | 两类场景文案逐字正确 |
| C7 | `dir` 不碰文档 | `kind = 'display'`、`requiresDocument = false`；不改 dirty、cwd、undo/redo，不触发 io 锁 | 未 `init` 直接 `dir` 正常；有文档时执行前后 `canvas`/`tree`/undo 不变 |

### 2.2 标签

| # | 任务 | 内容 | 完成标准 |
|---|---|---|---|
| C8 | `modified-star` | 实现 `TreeDecorator`；状态（保存点的每节点摘要表）放**实例字段**；订阅 `document:changed` 与保存事件 | 编辑后出现 `*`，保存后消失；代码里无模块级可变状态 |
| C9 | dirty 语义 | 二选一并写 ADR：①内容与上次保存不一致（`undo` 回到保存点后 `*` 消失）②发生过编辑命令（`undo` 不消失）；并说明新建节点是否立即标记 | 行为与 ADR 一致；推荐 ①，实现见下 |
| C10 | `(box)` | `kind === 'box'` 的行追加 `(box)`，不感知 `*` | `box` 行出现 `(box)`；与 `*` 同行时顺序符合 ADR |
| C11 | 拼接顺序与祖先传播 | 同一行多标签的拼接顺序写 ADR（示例里 `(box)` 紧跟 `g#n1`、`*` 在行尾，建议 `(box)` 在前、`*` 在后）；改子图形时祖先容器是否也标 `*` | 两个标签互不感知，只通过渲染器拼装 |
| C12 | 状态机测试 | 编辑 → 保存 → 再编辑 → `undo` 回保存点，四条分支都要有 | `npx vitest run plugins/tree-star` 全绿 |

**`modified-star` 的推荐实现（语义 ①，最简单也最好测）**：保存时把每个节点记成 `id → describe()` 存进实例字段；每次变更后用当前树逐节点比较，不一致的 id 打 `*`；`undo` 回到保存点时全部相等，`*` 自动消失。不需要自己维护差集。

## 5. 容易踩的坑

1. **`dir` 别写成 `kind = 'io'`**：`io` 会清空 undo 栈并上锁，直接违反「不触发 Phase 1 文档类命令的撤销限制」。
2. **排序别用 `localeCompare`**：中文/大小写/数字在不同 locale 下顺序不同，双装配"逐字节一致"会挂。用 `a < b ? -1 : a > b ? 1 : 0`。
3. **`[DIR]` 后面是两个空格**，不是制表符、不是对齐到固定列。
4. **`stats` 的 containers 包含 `box`**，但 `box` 自身的子节点里的叶子仍要计数；根 `<svg>` 不计入 containers。
5. **标签状态必须是实例字段**：模块级变量会让"两个插件互不感知"变成"两个实例互相污染"，也过不了源码检查。
6. **`(box)` 的判断不要写 `kind === 'box' || kind === 'g' && hasDataKind`**，就是 `kind === 'box'`；`g` 的降级不影响你。
7. **测试用替身**：`dir` 的替身继承 `DirectoryLister` 接口，真实目录用 `mkdtempSync` 建临时目录，测完删掉，别往仓库里塞测试文件。

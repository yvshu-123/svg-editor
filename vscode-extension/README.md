# SVG 文件标记与大纲

打开一个含 SVG 的文件夹，资源管理器会给 SVG 文件加上 `[]`。在文本编辑器中打开 `example.svg`，展开资源管理器下方的“大纲”，可以从 `svg → g#workflow → g#step → rect#start` 跳到矩形的开始标签。若文件默认显示为图片，在标签页菜单中选择“重新打开编辑器的方式 → 文本编辑器”。

## 打包与安装

开发环境使用 Node.js 22.12 或更高版本、npm，以及 VS Code 1.85 或更高版本。在仓库根目录执行：

```sh
cd vscode-extension
npm ci
npm test
npm run package
code --install-extension ./svg-editor-outline-0.1.0.vsix
```

也可以从 VS Code 扩展视图的菜单选择“从 VSIX 安装”。安装后重新加载窗口，然后打开示例所在的文件夹。资源管理器的“装饰标志”设置需要开启。若要验证独立安装，可给安装命令和打开工作区的命令传入相同的空目录作为 `--user-data-dir` 和 `--extensions-dir`（两者各用一个目录）。

## 自验

- 在一个文件夹中放置三个 SVG、一个名为 `assets.svg` 的目录、一个文本文件和一个无扩展名文件。检查三个 SVG 的标记；把其中一个改为 `.txt`，再改回来。切换颜色主题和文件图标主题后再检查。
- 打开示例，在原生大纲中依次展开两个分组，点击 `rect#start` 检查高亮的源码。未设置 id 的文本元素显示为 `text`。
- 修改 id 或插入子分组，观察未保存的编辑也会刷新大纲。删除一个 `</g>` 后大纲清空，撤销后恢复。
- 禁用扩展并重新加载窗口，检查两个功能都已停用。

大纲保留根元素和原始标签名。每个节点的范围覆盖整个元素，导航选区覆盖开始标签。为控制交互延迟，超过 2 Mi 个 UTF-16 码元的文档返回空大纲。
